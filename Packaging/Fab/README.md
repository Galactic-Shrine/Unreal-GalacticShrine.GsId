# GsId for Unreal Engine — Fab distribution

`GsId` provides 256-bit Galactic-Shrine identifiers for Unreal C++,
Blueprints, serialization, deterministic generation, and network replication.

| Item | Value |
| --- | --- |
| Plugin version | `__GSID_VERSION__` |
| Target engine | Unreal Engine `5.8` |
| Supported platforms | Windows 64-bit, Linux, macOS |
| Runtime module | `GsId` |
| Editor module | `GsIdEditor` |
| Distribution channel | Fab |
| License | Fab Standard License |

## Installation

Install the plugin through Fab, enable `GsId` in the Unreal Engine plugin
manager, and restart the editor when requested.
